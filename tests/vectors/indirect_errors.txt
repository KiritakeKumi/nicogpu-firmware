# INDIRECT error paths: nested INDIRECT, FENCE.IRQ in an IB, VMID 0,

# to the INDIRECT like the model's prefetch), reserved bits.  Each case
# recovers with CP_CTRL = ENABLE|RESET (RPTR := WPTR); an INDIRECT is
# 5 ring dwords.

ctrl 0
ctrl 1
irqclear
regclear

check error 0 0 0 0

ring 0x00040001 0x00000000 0x1 6 1
